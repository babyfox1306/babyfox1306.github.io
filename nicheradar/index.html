Lấy YouTube Data API key miễn phí

  1. Mở Google Cloud Console và tạo/chọn project.
  2. Bật YouTube Data API v3.
  3. Vào Credentials → Create credentials → API key.
  4. Nên giới hạn key theo website/referrer và chỉ cho YouTube Data API v3.
  5. Dán key vào NicheRadar. Key chỉ lưu localStorage trên thiết bị này.
